
# 🖥️ System Manager GUI (Tkinter)
<img width="442" height="607" alt="image" src="https://github.com/user-attachments/assets/7f6181ad-f533-4c7b-b940-e15c5559b56f" />

Простая программа на Python с графическим интерфейсом для управления выключением компьютера по таймеру.

Программа позволяет:

* ⏱ задать время в секундах
* 🔴 выключить ПК через указанное время
* ❌ отменить выключение
* 📂 открыть папку проекта
* 👤 показать имя пользователя и тип ОС

---

## 🚀 Возможности

* Графический интерфейс на `tkinter`
* Таймер обратного отсчёта
* Команда выключения компьютера
* Отмена запланированного выключения
* Открытие папки проекта
* Проверка введённого времени

---

## ⚙️ Требования

* Python 3.7+
* Windows

> Важно: команды `shutdown /s /t` и `shutdown /a` работают именно в Windows.

---

## ▶️ Запуск

```bash
python main.py
```

---

## 🖥️ Интерфейс программы

После запуска появляется окно:

```text
Управление системной
```

В программе есть:

| Элемент               | Описание                             |
| --------------------- | ------------------------------------ |
| Поле ввода            | сюда вводится время в секундах       |
| Выключить пк          | запускает выключение компьютера      |
| Открыть папку проекта | открывает папку, где лежит программа |
| отменить              | отменяет выключение                  |
| Таймер                | показывает, сколько секунд осталось  |

---

## 📂 Как пользоваться

### 1. Введи время

Например:

```text
60
```

Это значит, что ПК выключится через 60 секунд.

---

### 2. Нажми кнопку

```text
Выключить пк
```

Программа спросит подтверждение:

```text
Вимкнути ПК через 60 сек?
```

Если нажать **Yes**, будет запущена команда выключения.

---

### 3. Отмена выключения

Чтобы отменить выключение, нажми:

```text
отменить
```

После этого программа выполнит команду:

```bash
shutdown /a
```

И таймер остановится.

---

## 🧠 Как работает программа

Основная логика находится в функции:

```python
run_command(cmd_type)
```

Она принимает тип команды:

| Команда    | Что делает                       |
| ---------- | -------------------------------- |
| `shutdown` | выключает ПК                     |
| `restart`  | перезагружает ПК                 |
| `cancel`   | отменяет выключение/перезагрузку |

---

## ⏱ Таймер

За обратный отсчёт отвечает функция:

```python
start_ui_countdown(time_left)
```

Она каждую секунду обновляет текст:

```text
До діі залишилось: 59 сек
```

Для этого используется:

```python
root.after(1000, start_ui_countdown, time_left - 1)
```

## ⚠️ Возможные ошибки

| Ошибка                    | Причина                                      |
| ------------------------- | -------------------------------------------- |
| Введіть число секунд      | введён текст вместо числа                    |
| shutdown не работает      | программа запущена не на Windows             |
| Нет доступа               | система может требовать права администратора |
| Таймер не останавливается | команда уже была выполнена системой          |

## 📜 Пример работы

1. Пользователь вводит:

```text
120
```

2. Нажимает:


```text

```

5. Если нажать **отменить**, выполняется:
